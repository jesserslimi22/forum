# 04_VISUAL_LANGUAGE

## Purpose

Defines the visual identity that implementations must preserve.

## Current Direction

The website should feel:

- futuristic
- dark
- immersive
- spatial
- high-tech
- metallic
- atmospheric
- deep

The main visual language is:

- circular/cylindrical tunnel
- blue/cyan illumination
- strong depth
- cinematic spatial lighting
- high-tech surfaces
- compass-based identity

## Tunnel

The tunnel should communicate:

- depth
- scale
- continuity
- forward movement
- immersion

Avoid visible seams and visual elements that destroy the perception of physical space.

## Lighting

Lighting belongs to the 3D environment.

It should reinforce:

- depth
- direction
- movement
- landmarks
- compass elements
- destination spaces

## Motion

Motion should communicate physical movement through space.

Use controlled:

- acceleration
- forward travel
- deceleration
- camera movement
- depth effects

Effects must support the 3D experience rather than hide it.

## Compass

The compass is a central visual concept for this year's website.

Its visual treatment must remain consistent with the futuristic spatial environment.

## Visual Changes

New visual elements must fit the established visual language.

Major changes to the visual direction must be documented.
